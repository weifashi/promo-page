# 交付前检查

## 自动检查（assets/qa.cjs）

```bash
node assets/qa.cjs qa.config.json
```

配置示例（`qa.config.json`）：

```json
{
  "base": "http://127.0.0.1:8733",
  "pages": [
    {"name": "tr", "path": "/site/", "lang": "tr"},
    {"name": "en", "path": "/site/en/", "lang": "en"},
    {"name": "zh", "path": "/site/zh/", "lang": "zh-CN"}
  ],
  "widths": [320, 390, 768, 1440, 2560],
  "cta": "/app/signup/",
  "banned": ["即将推出", "Coming soon", "Yakında", "不是效果图"],
  "counts": {"#product .fm": 6, "#faq details": 6},
  "screenshots": "/tmp/qa-shots"
}
```

检查项：横向溢出（加载时 + 滚到底后）、`html lang`、只有一个 h1、所有图片加载成功且有 alt、**非铺底图片显示比例与原图一致（误差 1%）**、无 4xx/5xx、无 JS 报错、无非 GET 请求、禁用词、主按钮链接数量、区块数量、视频能自动播放。

## 人眼检查（自动检查替代不了）

每次汇报前看截图：每一屏 × 桌面 + 手机，至少一种语言；改过的区块每种语言都看。

## 被用户抓过的低级错误

| 错误 | 怎么发生的 | 预防 |
|---|---|---|
| 图片被压扁 | CSS reset 少了 `height:auto` | qa 比例检查 + 看截图 |
| 滚动条是系统白条 | 深色页没改滚动条 | 默认样式里就带 |
| 土耳其 İ 点错位、英文 ’ 变全角 | 拉丁文字用了中文字体 | 按 `html[lang]` 切字体栈 |
| 320px 横向溢出 | 设备光晕伪元素超出 | `overflow-x:clip` |
| 脚本整段不执行 | `const top` 与 `window.top` 冲突 | 避开全局名 |
| 视频不自动播放 | 系统「减少动态」被当成不播；被策略拦截没补播 | 见 visual.md |
| 只截一个角落，看不懂 | 为了「看清」裁局部 | 一律完整一屏 + 设备框 |
| 动图四角被卡片切掉 | 宽图溢出卡片底部 | 设备框完整放在卡片内 |
| 商品格没图，显得假 | 示例数据没有图 | 录制前给示例数据补图 |
| 两个 class 同名串样式 | 区块叫 `.ai`，徽标也叫 `.ai` | 区块类名加后缀 |
| 品牌名被转大写 | `text-transform:uppercase` + 土耳其语 | 品牌名不做大小写变换 |
| 大屏四周大片空白 | 列宽写死 px 上限 | 列宽用 vw |
| 首屏超过一屏 | 上下排布 | 宽屏两栏 + 按屏高限宽 |
| 动图框架和内容不匹配 | 先上线了新框架、动图还是旧比例 | 页面和素材一起上线 |
| 旧缓存 | 改了 CSS/JS 没换地址 | 地址带 `?v=` 版本号 |
