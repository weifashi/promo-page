# 开工表

> 能从代码、产品、现有页面查到的先自己填；剩下的一次性问用户。没填的项在交付时列出来。

| # | 项 | 说明 / 例子 | 填写 |
|---|---|---|---|
| 1 | 品类一句话 | 「为餐饮店打造的 AI 收银系统」——是什么 + 给谁 | |
| 2 | 目标客户 | 谁付钱、谁每天用、在哪个国家 | |
| 3 | 语言 | 主语言放根路径；其余语言 | |
| 4 | **别人没有、我们有** | 3–5 条，决定首屏和重点区块 | |
| 5 | 别人都有、我们也有 | 只进「全部功能」 | |
| 6 | 行业细分 | 页面要照顾到的客户类型（4–6 种） | |
| 7 | 主按钮 | 文案 + 直达的地址（注册 / 创建页，不经中间页） | |
| 8 | 演示入口 | 一键进示例账号的地址 | |
| 9 | 价格 | 免费档写价格；付费档写价格或「联系我们」 | |
| 10 | 换系统顾虑 | 和现有硬件 / 系统怎么对接、数据怎么迁 | |
| 11 | 信任事实 | 合规、数据存放地、认证、对接的品牌——只写能证明的 | |
| 12 | 公司信息 | 全称、地址、税号、隐私政策、用户协议、联系邮箱 | |
| 13 | 法规红线 | 营销短信 / 隐私 / 广告法；不能承诺的效果 | |
| 14 | 产品能否录屏 | 能就用真实界面；登录方式、示例数据怎么来 | |
| 15 | 官网先写、产品未做 | 列清单，随官网一起交付 | |
| 16 | 部署位置 | 预览地址、正式地址、谁有权限 | |
