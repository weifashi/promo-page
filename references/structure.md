# 版式与文案公式

## 首屏

- **kicker**（品牌名，小字、品牌色、字距拉开；不要对品牌名做 `text-transform:uppercase`——土耳其语会把 i 变成 İ）
- **h1**：品类一句话，两行，第二行加粗。例：「为餐饮店打造的 / **AI 收银系统。**」
- **副标题**：一句话列 3–4 个模块 + 一句独有卖点 + 一句行动。例：「收银、扫码点餐、厨房屏、自动营销，一套系统全包。再配一位不下班的 AI 店长。拍一张菜单，今天就能开卖。」
- **按钮**：主按钮（免费开始 →）+ 次按钮（▶ 观看演示，锚到视频）
- **右侧产品组合**：平板（主流程动图）+ 手机（客户侧动图，略倾斜叠在右侧）+ 一张数据卡（今日营业额 + 小柱状图，叠在左下）

布局要点：

```css
@media (min-width:901px){
  .hero{display:grid;grid-template-columns:minmax(0,33vw) minmax(0,min(50vw,calc((100svh - 260px)*1.7)));
        justify-content:center;align-items:center;gap:clamp(40px,4.5vw,88px);min-height:100svh}
  .hero h1{font-size:clamp(36px,3.5vw,92px)}
}
```

- 列宽用 vw，不用固定 px —— 固定上限会让大屏四周留白。
- 设备列宽同时受屏高限制，保证整组 ≤ 一屏。
- 文字和设备作为一个整体居中，中间间距固定。

## 信任条

5 条以内，每条前一个对勾。只写可验证的：对接品牌、合规、数据存放地、语言数、「免费开始，不用绑卡」。

## 产品家族轮播

- 每个模块：模块名、一句话、3 条卖点、一段完整一屏的动图。
- 交互：顶部模块名标签（aria tab）、左右箭头（大屏在卡片外侧，窄屏在卡片下方）、计数「1 / 6」、手机横滑、首尾循环、键盘左右键。
- 实现要点：`scroll-snap-type:x mandatory` 横向容器；点击箭头 / 标签时先 `mark(k)` 再 `scrollTo`，并在约 900ms 内忽略 scroll 事件，防止中途被改写；用户手滑停下（`scrollend` 或 250ms 防抖）后再识别当前页；窗口尺寸变化时滚回当前页。

## 行业方案

5 张竖卡：场景图铺底 + 底部渐变 + 名称 + 一句话。窄屏横滑。

## 独有能力（每项一行）

- 左文：kicker（能力名）、h3（结果句）、一段说明。
- 右图：设备截图 + 一张浮动「结果卡」（AI 读完了菜单 / 改价前后 / 今日简报）。
- 左右交替。

## 独有模块（例：营销引流）

- 标题公式：「客人，**自己会回来。**」——写结果，不写功能名。
- 清单 5 条：每条「机制名 + 一句做法」。
- 右侧模拟卡：消息、评论 + AI 拟回复、生日礼、一个数据卡（示意数字，不承诺）。

## 价格

两档：免费（写清限制）/ 付费（价格或「联系我们」+ mailto）。下方一行注释（适用范围、升级数据保留）。

## FAQ（换系统必问）

现有设备能不能用 / 换过来麻烦吗 / 第三方平台订单 / 断网怎么办 / 数据安全 / 免费是不是真免费。

## 结尾与页脚

- 结尾：品牌名小字 + 「开始使用 XX。」+ 一句行动 + 主按钮 + 演示入口 + 三条承诺（没有期限 / 没有开通费 / 数据属于你）。
- 页脚四栏：产品（各模块锚点）/ 方案（各行业）/ 资源（视频、功能、价格、FAQ、示例）/ 公司（联系、登录、开始）+ 品牌一句话 + 邮箱 + © + 语言切换。
